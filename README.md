# Physical AI R&D Partner · 한국어 연구개발·유지보수 파트너

**문제를 정확히 표현하기 어려운 순간부터, 코드 수정과 실험 결과를 판단하는 순간까지 AI와 함께 연구개발하기 위한 Codex 스킬입니다.**

`physical-ai-rnd-partner-ko`는 한국어로 일하는 Physical AI 개발자·연구자를 위해 작성했습니다. 현장에서 본 현상과 가설을 출발점으로 AI가 자료·코드·로그를 조사하고, 대안을 비교하며, 허용된 구현과 검증을 수행하도록 안내합니다.

“도메인을 잘 몰라서 무엇을 시켜야 할지도 모르겠어”라고 시작해도 됩니다. AI는 필요한 확인과 판단 근거를 구체화하고, 사용자는 관찰·목적·제약·의견으로 연구에 참여합니다.

> **스킬 이름:** `physical-ai-rnd-partner-ko`  
> **주요 언어:** 한국어  
> **용도:** 연구 방향 탐색 · 공동 설계 · 구현 · 디버깅 · 실험 · 평가 · 통합 · 유지보수

## 어떤 방식으로 협업하나요?

### 관찰에서 시작하고, 원인은 검토합니다

“상자가 미끄러진다”는 관찰과 “그립 힘이 약하다”는 가설을 구별합니다. AI는 기존 영상·로그·코드에서 처음 어긋나는 지점을 찾고, 어떤 확인이 원인 후보를 구별하는지 설명합니다.

### AI가 맡을 작업을 구체화합니다

접근 가능한 자료 조사, 변경, 검증은 AI가 수행하도록 안내합니다. 사용자는 현장 관찰과 목적을 제공하고 추천에 반론하거나 전제를 정정할 수 있습니다. 정정된 내용은 다음 실험과 결론에 반영합니다. 필요한 개념은 현재 결정과 연결해 설명합니다.

### 코드와 모델의 성공을 구별합니다

다음 관찰은 각각 다른 범위의 근거입니다.

| 확인한 것 | 추가로 판단해야 할 것 |
|---|---|
| mock을 사용한 테스트 통과 | 실제 정책·장치 경로도 동작하는가? |
| loss 감소·체크포인트 생성 | 목표 행동과 작업 지표가 개선됐는가? |
| 교사 IK가 개입한 성공 영상 | 정책 단독의 수행 능력은 어떠한가? |
| 시뮬레이션 성공 | 실제 센서·제어·물리 조건에서도 성립하는가? |
| 성공 사례 하나 | 실패를 포함한 비교와 반복 변동은 어떠한가? |

### 변경의 영향과 복구를 함께 봅니다

코드 외에도 데이터·전처리·정규화·가중치·캐시 명령·환경·평가 조건의 의존관계를 살핍니다. 중요한 결정의 이유와 불이익, 재검토 조건, 이전 정상 구성으로 돌아갈 방법을 기존 프로젝트 기록에 연결합니다.

## 대화 예시

다음은 협업 방식을 보여주는 가상의 예시입니다.

**사용자**  
상자를 놓치는데 더 학습하면 될까? 어디부터 볼지 모르겠어.

**AI**  
추가 학습이 필요한지는 아직 미정이야. 먼저 기존 기록에서 손이 닿기 전부터 어긋나는지, 잡은 뒤 미끄러지는지 확인하겠어. 두 경우는 우선 볼 입력·접촉·제어 경계가 달라.

**사용자**  
다시 보니 닿기 전부터 손이 상자보다 위로 가.

**AI**  
그러면 파지 후 힘 부족을 우선 보던 계획을 바꿔야 해. 먼저 물체 기준점·좌표 변환·관측 시점과 손 목표를 같은 시점에서 연결해 볼 근거가 생겼어. 원래 물체 위치→변환 후 위치→정책 입력→목표 출력 순서로 확인하고, 그 결과에 따라 수정이나 학습을 선택하자.

## 설치 방법 상세

이 저장소는 텍스트 지침과 참고문서로 구성됩니다. 스킬 설치 자체에는 GPU·ROS·시뮬레이터·모델 가중치가 필요하지 않습니다. 실제 프로젝트의 코드 실행과 학습에 필요한 환경·권한은 별도로 준비해야 합니다.

### 방법 A — Codex의 Skill Installer

위의 [빠른 시작](#빠른-시작) 메시지를 사용합니다. 저장소 안의 설치 경로는 다음과 같습니다.

설치가 이미 되어 있으면, 기존 사본의 위치와 변경 내용을 확인한 뒤 업데이트를 요청하세요. 같은 이름의 사본을 여러 위치에 설치하는 것은 피하는 편이 관리하기 쉽습니다.

### 방법 B — 직접 복사하기 · macOS/Linux

Git과 POSIX 호환 셸이 있는 환경에서 실행합니다.

```bash
git clone https://github.com/eunsu0325/Physical-AI_R-D_Partner_skill.git
cd Physical-AI_R-D_Partner_skill

mkdir -p "$HOME/.agents/skills"
if [ -e "$HOME/.agents/skills/physical-ai-rnd-partner-ko" ]; then
  echo "이미 설치된 스킬이 있습니다. 기존 사본을 확인한 뒤 업데이트하세요."
else
  cp -R skills/physical-ai-rnd-partner-ko "$HOME/.agents/skills/"
fi
```

개인 설치 위치로 공식 문서의 `~/.agents/skills`를 사용한 예시입니다. 내장 설치기는 해당 환경의 Codex 스킬 경로를 사용할 수 있습니다. 기존 사본이 `~/.codex/skills` 등에 있다면 위치를 먼저 확인하고 한 사본을 관리하세요. [설치 위치와 중복 이름 처리](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

Windows에서는 저장소의 `skills/physical-ai-rnd-partner-ko` 폴더 전체를 사용자 홈의 `.agents/skills/` 아래에 복사할 수 있습니다. 최종적으로 `physical-ai-rnd-partner-ko/SKILL.md`가 바로 보이는 구조인지 확인하세요.

## 연구 근거와 검증 범위

이 스킬은 인간–AI 협업 연구, ML 시스템 공학, 실험·재현성 연구와 로봇 인터페이스 지침을 참고했습니다. 근거 문서에는 기존 준비 조사 21개와 생성 전 추가 확인 5개의 **본문 전체/선택 독해 범위와 한계**를 구별해 기록했습니다.

- 협업: AI를 이용한 탐색과 구현 가속, 사용자의 정정, 설명과 판단의 연결.
- 연구: 기준 비교, 데이터 분할, 표본 단위, 변동·실패·회귀, 실행 예산.
- 유지보수: 코드·데이터·모델·환경의 의존관계, 검토 가능한 변경, 결정 기록과 복구.
- Physical AI: 좌표·단위·시각·관절 순서·행동 의미, SIM과 실물 증거의 범위.

작성 과정에서는 스킬 형식·내부 참조 검사, 대표 요청의 응답 점검, 독립 검토, 격리된 작은 코드 수정 사례를 확인했습니다. 이는 지침과 작업 수행 범위에 대한 점검입니다. 실제 사용자의 생산성·학습·장기 유지보수 비용·로봇 성공률 개선을 측정한 실험은 아닙니다.

각 연구의 결과를 이 스킬의 효과로 일반화하지 않습니다. 자세한 출처는 [근거 문서](skills/physical-ai-rnd-partner-ko/references/evidence.md)를 확인하세요.

## 자주 묻는 질문

**논문을 처음부터 배우는 용도로도 쓰나요?**  
이 스킬은 현재의 연구·개발 결정을 돕는 설명에 집중합니다. 독립적인 논문·개념 학습은 별도 `physical-ai-mentor-ko`의 용도입니다. 그 멘토는 이 저장소에 포함하지 않았고, 이 스킬 설치의 필수 의존성도 아닙니다.

**설치하면 로봇이나 GPU 서버가 자동으로 연결되나요?**
